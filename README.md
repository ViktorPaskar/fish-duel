# Fish Duel

Рыболовная дуэль для двоих в GTA VI: кто вытащит рыбу тяжелее. Записываете вид, вес в кг (или lb/oz, как в игре) и место на карте Леониды, а табло обновляется у обоих онлайн.

- Комната по 5-значному коду, без регистрации
- Прямое соединение между устройствами (WebRTC через PeerJS), улов хранится на каждом устройстве и синхронизируется при подключении
- Табло, карта с метками улова, журнал, виды (в игре 35, публично подтверждены 8, остальные добавляются по ходу игры)

Карта: официальная карта Леониды © Rockstar Games (rockstargames.com/VI/downloads), нарезана на тайлы в полном разрешении 5365×7491 (без рамки постера).

# Fish Duel

Рибальська дуель для двох у GTA VI: у кого риба важча. Записуєте вид і вагу (lb/oz, як на екрані улову в грі), а таблиця лідерів оновлюється в обох онлайн.

- Кімната за 5-значним кодом, без реєстрації
- З'єднання напряму між пристроями (WebRTC через PeerJS), улов зберігається на кожному пристрої й синхронізується при підключенні
- Таблиця лідерів, рекорди за видами, стрічка улову, колекція видів (35 у грі)

Фанатський проєкт, не пов'язаний із Rockstar Games.
